四 · 严重度 .ops-sev / 异常卡 .ops-anomaly-danger

严重 警告 提示

形状 + 颜色双编码：实心圆 / 三角 clip-path / 空心圆。色弱也能分辨，不要只用颜色。

动效纪律

脉冲只作用于描边与圆点，绝不作用于文字（闪烁文字不可读）。
@media (prefers-reduced-motion: reduce) 下全站动效自动关闭。

异常卡必须两行：① 圆点 + 标题 + 数量 + 指派 + 箭头；② 详情 + 明细 + 知道了 + 关闭。
挤成一行时（异常带列宽仅 280/320），「知道了」会被压成 27×51px 竖排三字 —— 2026-11-25 实测踩过。
所有操作控件要 flex-shrink:0 + white-space:nowrap；::before 是左侧 4px 红条。

七 · 这份皮肤不含什么

不含业务逻辑：数据聚合、阈值判定、告警关闭留痕都在 opsDeck/useOpsDeckData.ts 与 useOpsLocalData.ts，本页只画。真实大屏的完整结构与交互见 opsDeck/OpsDeckV2.tsx。
